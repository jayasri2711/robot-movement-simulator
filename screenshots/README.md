# Robot Movement Simulator — Screenshots

This folder contains screenshots demonstrating the Robot Movement Simulator.

## Screenshots

1. **Initial Grid and Commands** — Displays the 5 × 5 grid, robot position, goal, obstacles, and available commands.
2. **Sensor Scan and Obstacle Detection** — Shows sensor readings and the simulator's obstacle-detection response.
3. **Goal Reached and Final Report** — Displays the final robot position, navigation path, movement count, and collision statistics.

These screenshots illustrate example runs of the C++ console-based robot simulation.
